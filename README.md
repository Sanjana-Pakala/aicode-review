aicode-review
The AI Code Reviewer is a web-based application that analyzes user-submitted code and provides real-time feedback using AI. It detects errors, suggests improvements, and explains code in a simple way to help developers write better programs. The system is built using Flask for backend and AI API integration for intelligent code analysis.

Features
- Real-time code analysis  
- Error detection and suggestions  
- Code improvement recommendations  
- Simple and beginner-friendly explanations  
- Supports multiple programming languages (based on AI model capability)
  
Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- AI Integration: OpenRouter / Gemini / LLM API  
- Communication: REST API (JSON)

 How It Works
1. User enters code in the frontend  
2. Frontend sends code to Flask backend  
3. Backend forwards request to AI model  
4. AI analyzes the code and generates feedback  
5. Response is sent back to frontend  
6. Output is displayed in the browser
